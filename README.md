# הדגמת עץ המשפחה

אתר סטטי לאינטראקציה והצגת רעיון העץ. הוא משתמש בצילום מצב קבוע מתוך קובצי הייצוא בזמן יצירתו, ופרופילי המשפחה אינם נטענים ממסד נתונים ואינם מתעדכנים. לחיצה על עיגול של בן משפחה פותחת את העמודה הבאה; לחיצה נוספת על אותו אדם פותחת את כרטיס הפרופיל.

## פרסום ב-GitHub Pages

1. העלו את תוכן התיקייה הזו למאגר GitHub חדש.
2. ב-GitHub פתחו **Settings → Pages** ובחרו בפריסה מהענף הראשי, מתיקיית השורש.
3. שמרו והמתינו לכתובת שהאתר מציג.

האתר כולל שמות ותמונות משפחתיות. מי שיכול לגשת לאתר הציבורי יוכל לראות ולהעתיק אותם. לפני פרסום, כדאי לעבור על התוכן ולוודא שכל בני המשפחה מסכימים.
