# הדגמת עץ המשפחה

אתר סטטי לאינטראקציה והצגת רעיון העץ. הוא משתמש בצילום מצב קבוע שנשמר ב-`demo-data.json`; הוא אינו מתחבר למסד נתונים ואינו מתעדכן אוטומטית. לחיצה על עיגול של בן משפחה פותחת את העמודה הבאה; לחיצה נוספת על אותו אדם פותחת את כרטיס הפרופיל.

האתר כולל שמות ותמונות משפחתיות, והאתר הציבורי מאפשר לכל אחד לצפות ולהעתיק אותם.
